# Rate Repository App

Full Stack Open - Part 10: React Native

A React Native application built with Expo, Apollo Client and GraphQL.

## Features

- Browse and search repositories
- Sort repositories by rating
- Sign up and sign in
- View repository details and reviews
- Create and delete reviews
